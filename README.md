# TUVAL App Movil

Aplicacion Flutter para TUVAL.

Para entender la estructura del proyecto, los flujos funcionales, ambientes,
endpoints, comandos de ejecucion y puntos de extension, revisa:

- [Guia de desarrollador](docs/guia_desarrollador.md)

Prompts para colaboradores, respetando la estructura del proyecto y con PR a
`develop` (pruebas), sujeto a aprobación de TuvalSystems, devtuval o josemg23:

- [Crear una funcionalidad](docs/prompts/crear-funcionalidad.md)
- [Modificar o actualizar una funcionalidad](docs/prompts/modificar-funcionalidad.md)

Estas reglas aplican al invocar los prompts; no restringen el trabajo directo
del propietario ni configuran protecciones globales de GitHub.
